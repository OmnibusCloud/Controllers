typescript-sucrase-3.35.1/ of the language runtimes of the OmnibusCloud Verify controller

What this folder carries: sucrase.js, the transform of sucrase 3.35.1 with the packages it
needs, from npm by the integrity hashes of the toolchain's lock file, bundled into one script by
esbuild 0.25.10. QuickJS loads it before a TypeScript task.

This file is written by a tool (toolchain/notices in the controller's repository,
https://github.com/OmnibusCloud/Controllers), and a build job fails when the committed file is
not what the tool writes. No text here is written from memory: each is a file, or a named part
of a file, at the address given with it, held to the SHA-256 given with it, or a file that lies
beside this one. A text is unchanged but for its line ends.

The controller itself is its authors' work under the MIT licence. This file is about what it
carries of others.
