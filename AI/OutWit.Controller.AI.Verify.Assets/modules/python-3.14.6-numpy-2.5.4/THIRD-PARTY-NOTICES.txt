What this folder carries: python-plain.wasm, CPython 3.14.6 built for WASI by the controller's
toolchain with wasi-sdk 24, with numpy 2.5.4's compiled modules linked in; python.wasm, the same
interpreter caught after it started and imported numpy; lib/python314.zip, the standard library
as bytecode; lib/numpy-2.5.4.zip, numpy's Python package as bytecode. The parts below are those
programs and what is linked into the two modules.

BUILD.txt, beside this file, says how the modules were built and names the changes made to
numpy's sources; the changes themselves are in patches/.

This file is written by a tool (toolchain/notices in the controller's repository,
https://github.com/OmnibusCloud/Controllers), and a build job fails when the committed file is
not what the tool writes. No text here is written from memory: each is a file, or a named part
of a file, at the address given with it, held to the SHA-256 given with it, or a file that lies
beside this one. A text is unchanged but for its line ends.
